ข้อ 2

ภาพและคำตอบที่ถูกต้อง

อย่างน้อย 50 ภาพ พร้อม ground truth

ใช้ภาพจาก Oxford-IIIT Pet Dataset ซึ่งเปิดให้ใช้เพื่อการศึกษา ข้อดีคือเขาทำ ground truth ระดับ pixel มาให้แล้ว เราจึงไม่ต้องนั่งระบายเอง และได้คำตอบที่มีคุณภาพสม่ำเสมอ

คัดมา 60 ภาพ (โจทย์ขออย่างน้อย 50) เฉพาะพันธุ์ Scottish Terrier และเลือกเฉพาะภาพที่ตัวหมากินพื้นที่ระหว่าง 15% ถึง 70% ของภาพ เพื่อให้ได้ภาพที่เป็น "หมา 1 ตัวบนพื้นหลัง" จริง ๆ ไม่ใช่ภาพที่หมาเล็กจิ๋วหรือใหญ่เต็มจอ ทุกภาพย่อให้ด้านยาวสุด 400 pixel

ค่า 3 คือแถบรอบตัวหมาที่คนทำ ground truth เองก็ตัดสินไม่ได้ว่าเป็นขนหรือพื้นหลัง เราจึงตัดออกไม่นำมานับ ซึ่งเป็นวิธีมาตรฐาน แต่แถบนี้กินพื้นที่ เฉลี่ย 13.7% ของภาพ (บางภาพถึง 36.6%) จึงมีบางภาพที่ได้ IoU เกือบ 1.00 ไม่ใช่เพราะทายถูกเป๊ะ แต่เพราะส่วนที่ทายพลาดดันไปตกอยู่ในแถบที่ไม่นับพอดี

ข้อ 3

วิธีที่ออกแบบ

สร้าง algorithm แยกวัตถุออกจากพื้นหลัง

ไอเดียหลัก

แทนที่จะพยายามสอนโปรแกรมว่า "หมาหน้าตาเป็นอย่างไร" ซึ่งยากมาก เรามองกลับด้าน คือให้โปรแกรมรู้ว่า "พื้นหลังหน้าตาเป็นอย่างไร" แทน

ขอบภาพรอบนอกเกือบทั้งหมดคือพื้นหลัง เอาสีตรงนั้นมาเฉลี่ยก็ได้สีพื้นหลังคร่าว ๆ จากนั้น pixel ไหนที่สีต่างจากพื้นหลังมาก ก็น่าจะเป็นตัวหมา

  1. หาสีเฉลี่ยของขอบภาพ ใช้ขอบรอบนอก 10% เป็นตัวอย่างของพื้นหลัง
  2. วัดว่าแต่ละ pixel สีต่างจากพื้นหลังเท่าไร ได้ "ภาพคะแนน" 0–255 ยิ่งสว่างยิ่งน่าจะเป็นหมา
  3. ตัดภาพคะแนนเป็นขาว-ดำ ด้วย Otsu Otsu หาเส้นแบ่งให้เองอัตโนมัติ ไม่ต้องตั้งค่าเอง
  4. เก็บกวาดด้วย Morphology ส่วนนี้คือหัวใจของโจทย์ข้อ 4

วัดสีในปริภูมิ CIE-Lab ไม่ใช่ RGB เพราะระยะห่างใน Lab ใกล้เคียงกับที่ตามนุษย์รู้สึกว่า "สีต่างกันแค่ไหน" มากกว่า และเบลอภาพด้วย median filter ก่อนเพื่อลด noise

ทำไมต้องมีภาพคะแนน ไม่ตัดขาว-ดำเลย

เพราะ ROC curve ในข้อ 5 ต้องไล่เส้นแบ่งไปทีละค่าตั้งแต่ 0 ถึง 255 ถ้าโปรแกรมคืนมาแค่ภาพขาว-ดำ จะไล่ threshold ไม่ได้ วาด ROC ไม่ได้

ข้อ 4

ทดลอง Morphology

ปรับปรุงผลลัพธ์กระบวนการ Segmentation

ตามนิยามใน Lecture 10 การทำงานทั้งหมดถูกควบคุมด้วยรูปร่างของ Structuring Element

Dilation   I ⊕ H = { z | Ĥz ∩ I ≠ ∅ }     Erosion   I ⊖ H = { z | Hz ⊆ I }
Closing   I • H = (I ⊕ H) ⊖ H   คือขยายก่อนแล้วค่อยหดกลับ

ทำอะไรบ้าง

ผลจาก Otsu มีปัญหา 2 อย่าง คือมีรูโหว่อยู่ในตัวหมา (ตรงที่ขนสะท้อนแสงจนสีใกล้พื้นหลัง) และตัวหมาขาดเป็นชิ้น ๆ เราจึงทำ

  1. Closingขยายก่อนแล้วหดกลับ เชื่อมชิ้นส่วนที่ขาดให้ติดกัน
  2. Region fillingอุดรูโหว่ที่ถูกล้อมอยู่ข้างในตัวหมา

ไม่ใช้ Opening เพราะทดลองแล้วทำให้แย่ลง ส่วนที่บางอย่างขา หาง และหูจะโดนลบหายไป

อ่านตารางนี้อย่างไร Morphology ทำให้ Recall พุ่งจาก 0.752 เป็น 0.905 คือเก็บตัวหมาได้เกือบครบ แต่ต้องแลกด้วย Precision ที่ลดลงเล็กน้อยจาก 0.676 เหลือ 0.650 เพราะการขยายภาพทำให้กินพื้นหลังรอบ ๆ เข้ามาด้วย เมื่อรวมทั้งสองด้าน F1 และ IoU ดีขึ้นชัดเจน

ที่น่าสนใจคือ Accuracy แทบไม่ขยับเลย (0.778 → 0.788) ทั้งที่ผลลัพธ์ดีขึ้นเห็น ๆ เพราะพื้นหลังมีสัดส่วนมากกว่าตัวหมา ทายพื้นหลังถูกเยอะ ๆ ก็ดัน Accuracy ให้สูงได้แล้ว นี่คือเหตุผลว่าทำไมงาน segmentation จึงไม่ควรดู Accuracy อย่างเดียว

ROC Curve

ข้อสังเกตที่ควรพูดตอนนำเสนอ

ทั้งสองจุดอยู่บนเส้น ROC เส้นเดียวกัน เพราะภาพคะแนนเป็นตัวเดิม Morphology ไม่ได้ทำให้ภาพคะแนนดีขึ้น แต่ทำให้ผลลัพธ์ขยายตัวขึ้น ซึ่งมีผลคล้ายกับการลด threshold ลง

ประโยชน์จริงของมันจึงไม่ใช่แค่ตัวเลข แต่คือรูปร่างของผลลัพธ์ คือได้ก้อนวัตถุที่เป็นชิ้นเดียวขอบเรียบ ไม่มีรูโหว่ ซึ่งเอาไปใช้งานต่อได้จริง ต่างจากการลด threshold เฉย ๆ ที่ได้ผลลัพธ์เป็นจุด ๆ กระจัดกระจาย

ภาพที่ทำได้ดีและภาพที่ล้มเหลว

สาเหตุที่ล้มเหลว ทั้งสามภาพล่างเป็น Scottish Terrier ขนสีอ่อน (สีครีม) ซึ่งสีใกล้เคียงกับพื้นไม้และผนังในภาพ สมมติฐานหลักของวิธีเราคือ "สีของหมาต่างจากสีพื้นหลัง" จึงพังทันที ภาพคะแนนผิดตั้งแต่ต้น ตัดด้วย Otsu ออกมาก็เละ

และที่สำคัญ Morphology ช่วยกรณีนี้ไม่ได้เลย ยิ่งทำให้แย่ลงด้วยซ้ำ เพราะมันแค่ขยายและเชื่อมสิ่งที่ผิดอยู่แล้วให้กลายเป็นก้อนใหญ่และเรียบขึ้น บทเรียนคือ Morphology เป็นเครื่องมือเก็บกวาด ไม่ใช่เครื่องมือแก้ผิดให้เป็นถูก

ข้อ 6

สรุปสำหรับนำเสนอ

ประเด็นหลักและสิ่งที่ทำได้ครบตามโจทย์

สามประเด็นที่ควรพูด

  1. วิธีง่าย ๆ ก็ทำงานได้ — แค่เอาสีขอบภาพมาเฉลี่ยเป็นสีพื้นหลัง แล้ววัดว่าแต่ละ pixel ต่างจากพื้นหลังแค่ไหน ก็ได้ AUC 0.814 แล้ว
  2. Morphology ช่วยได้จริง และพิสูจน์บนภาพที่ไม่เคยใช้ปรับค่า — IoU ชุดทดสอบดีขึ้นจาก 0.583 เป็น 0.620 ตัวช่วยหลักคือ Closing กับ Region filling ส่วน Opening ทำให้แย่ลงเพราะไปลบขา หาง และหูที่บางกว่า SE
  3. Morphology เก็บกวาดได้ แต่แก้ของที่ผิดตั้งแต่ต้นไม่ได้ — ภาพหมาขนสีอ่อนที่กลืนกับพื้นหลัง ทำ Morphology แล้วยิ่งแย่ลง เพราะมันขยายส่วนที่ผิดให้ใหญ่ขึ้น
